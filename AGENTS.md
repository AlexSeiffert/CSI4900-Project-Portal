# Instructions for AI agents (Codex, Claude Code, and others)

These rules apply to the whole repository. Read them before you edit anything.

## Keep the READMEs accurate

If you make a significant change, update the README that covers it so it matches the code as it now stands.
Write it as the current state, not as a change: no changelogs, dates, or "now", "added", "removed".
Small tweaks don't need a README update.

## Other rules

- Don't commit or push unless the user asks.
- Only write code comments when they are absolutely necessary, such as explaining something that can't be understood from the code itself. Don't narrate what the code does.
- Brand colours and typography come from `frontend/BRAND.md`. Use the frontend's colour tokens, not raw hex values. Ask for user's permission before making any changes to the brand.
