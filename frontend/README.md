s# Frontend

This directory is reserved for the Project Portal UI. Implementation and framework
selection are deferred.

Keep the UI application, its dependencies, configuration, tests, and build scripts
in this directory when implementation begins. Document its setup and run commands
here and link them from the repository README.

The UI will consume the backend's `/api/v1` REST endpoints. See the
[backend guide](../backend/README.md) for the current architecture and project routes.
